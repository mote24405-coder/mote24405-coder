# データを使って、探しやすいサービスを作っています

Python / FastAPIを中心に、情報整理・検索・推薦機能を持つWebアプリを開発しています。

## 代表作品：滋賀大学 研究室探索アプリ

修士論文117件を整理し、59研究室の研究テーマ・手法・使用データから
興味に合う研究室を探せるWebアプリです。

- 機能：絞り込み、全文検索、研究室の推薦、管理画面
- 技術：Python、FastAPI、PostgreSQL、SQLAlchemy、HTMX、Tailwind CSS
- [コードを見る](https://github.com/mote24405-coder/shiga-lab-recommend)
